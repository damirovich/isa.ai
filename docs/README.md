# Документация ISC.AI («ИнспекторAI»)

Комплект проектной документации платформы ведомственного внутреннего контроля ISC.AI. Документы ведутся в репозитории под версионным контролем, синхронно с кодом (ТЗ, раздел 9.3): изменение поведения системы сопровождается обновлением соответствующего документа в том же изменении.

**Главный источник истины — ТЗ (ДОК-01).** Все идентификаторы требований (ТС/ТП/ТН/ТНД/ТЭ/ТБ/ТСТ/ТОБ/ТИ/ТФ/ТО/ПР/КИ/GATE/ПОДГ/ДОК/ТД) определены в нём; прочие документы ссылаются на эти идентификаторы. При расхождениях приоритет имеет ТЗ.

> **Состояние проекта.** Рабочий этап **Э0** — собран компилируемый архитектурный каркас (14 проектов на .NET 10); функциональный код, контракты, слой данных, подсистема ИИ и тесты ещё не реализованы. Все документы — черновики версии 0.x для согласования; значения, требующие данных заказчика, помечены «уточняется с заказчиком (Э1)».

## Порядок чтения

- **Для согласования концепции и приёмки** — ДОК-01 (ТЗ), затем ДОК-02 (архитектура) и ДОК-03 (модель угроз).
- **Для разработчиков** — ДОК-05 (контракты), ДОК-04 (схема данных), ДОК-06 (ADR), ДОК-10 (стандарт кода).
- **Для эксплуатации и приёмки** — ДОК-07 (администратор), ДОК-08 (пользователь), ДОК-09 (испытания).

## Статус документов

Все документы прошли внутреннее ревью на согласованность с ТЗ (соответствие идентификаторов требований, режимные инварианты, проверяемость). Замечания ревью внесены. Документы остаются черновиками версии 0.x: ключевые значения (пороги метрик, версии моделей, класс защищённости, состав модулей, НФТ) фиксируются на рабочем этапе Э1 совместно с заказчиком.
