# Э5-06 — Анализ / Сравнение (§5.2.3, ТФ-НПА-03/04)

**Ветка:** `feature/npa-analysis` · **Дата:** 2026-08-24 · **Статус:** готово (последний P1)

## Что это

Два вдумчивых сценария на конвейере Генератора (демо-витрина снята):

- **Сравнение по теме (ТФ-НПА-04):** тема («сроки регистрации документов») → извлечение норм
  РАЗНЫХ актов (TopK расширен до 16) → аналитическая записка: ПРОТИВОРЕЧИЯ (какие акты и в чём
  расходятся, риск, предлагаемое действие) / ПРОБЕЛЫ / РЕКОМЕНДАЦИИ. Промпт требует считать
  противоречием только действительное расхождение норм и прямо писать «не найдено», если чисто.
- **Анализ документа (ТФ-НПА-03):** вставленный текст → заключение: правовой (соответствие нормам
  корпуса, с дословными ссылками), организационный (исполнимость), управленческий (цель, риски)
  анализ + выводы и предложения.

Выводы ИИ — проект для человека (ТБ-042); каждая ссылка проходит грунтовку (GATE-2);
экспорт в .docx с грифом (общий экспортёр, ТБ-033).

## Роли моделей = пресеты скорости (ADR-0011, закреплено этой веткой)

- **Draft — быстрая, БЕЗ размышлений:** Генератор, Методики, Редактор, Чат-ассистент (переведены
  явной ролью; у чата сменён дефолт `ChatMessageRequest.Role`). Секунды–десятки секунд на ответ.
- **Analysis — вдумчивая, С размышлениями:** сценарии этого модуля. Минуты на ответ — поиск
  действительных расхождений того стоит; страница честно предупреждает о времени.
- Механика: по-ролевое переопределение `Llm:Models:{role}:DisableThinking` поверх глобального
  `Llm:DisableThinking` (читается в `AddCoreAiModels`, применяет `LegacyMaxTokensPolicy`
  через `chat_template_kwargs.enable_thinking`). В `appsettings.json` Analysis: `DisableThinking: false`.

## Тесты

`AnalysisScenariosTests` (юнит): оба шаблона встроены и рендерят вход (заголовки-комментарии
не протекают); сравнение идёт ролью Analysis с расширенным TopK; анализ документа строит тему
извлечения из НАЧАЛА документа; результат всегда HITL. Плюс guard пустого ответа в обоих хендлерах.

- Структурированные карточки находок (вывод — текст-записка; парсинг находок хрупок).
- ТФ-АНПА-01/02 (проекты приказов со сверкой до подписания) — отдельный модуль очереди.
