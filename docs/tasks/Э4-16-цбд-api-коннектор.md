## Контекст
Скрапинг SPA ЦБД (Э4-15) даёт только **каталог** (заголовки+ссылки), но **не текст акта** (он не в DOM). Реверс сетевых запросов выявил **официальный API** (проверено — работает обычным HTTP, без браузера):
- **`POST /api/v1/GetDocuments?pageNumber=&pageSize=`** → список: `documentCode, nameRu, nameKg, status, vid, lastEdition` (всего 207281 док.). Есть **`status`** («Действует» / «Утратил силу» …).
- **`GET /api/v1/GetEdition?editionId=&lang=ru`** → `contentRu` / `contentKg` — **полный текст акта** (Word-HTML; для Конституции ~227 000 символов).

## Цель
Коннектор, который берёт из ЦБД **только действующие** НПА с **полным текстом** (ru), через официальный API — вместо скрапинга.

## Что сделать
- ⏳ `CbdApiConnector : ISourceConnector` (Id `cbd-api`): пагинация `GetDocuments` → фильтр `status == "Действует"` (whitelist, fail-closed) → по каждому `GetEdition(lastEdition, lang=ru)` → `contentRu` → снять Word-HTML в текст (переиспользуя `HtmlContentExtractor`).
- ⏳ Маппинг в `HarvestedDocument`: Title=`nameRu`, Text=текст, DocType=`vid`, Metadata={status, editionId, documentCode}, Language=ru.
- ⏳ DI: типизированный `HttpClient` с реалистичным UA (API отдаёт данные, дефолтный бот-UA сайт режет).
- ⏳ Тест: фейковый HTTP-обработчик (GetDocuments со смешанными статусами + GetEdition) → в пакет попадают ТОЛЬКО действующие, с текстом.

## Критерии приёмки
- Собранные документы содержат **реальный текст акта** (а не «шапку» сайта).
- В пакет попадают **только `Действует`**; утратившие силу отсеяны.

## Осталось / риски
- Серверный фильтр статуса в теле `GetDocuments` (сейчас — клиентский фильтр + пагинация) — уточнить схему тела для эффективности на 207k.
- `contentKg` (кыргызский) — добавить второй язык при необходимости (ТО-лнг-01).
- `lastEdition` → доменная модель редакций (Э4-02/Э4-14): версии/замена.
- Вежливость к источнику: пагинация с разумным лимитом; легальность — официальный публичный API.

## Результат (реализовано)
- [`CbdApiConnector`](../../src/tools/ISC.AI.Harvester/Connectors/CbdApiConnector.cs) (`ISourceConnector`, Id `cbd-api`): пагинация `GetDocuments` → whitelist `status == "Действует"` → `GetEdition(lastEdition, lang=ru)` → `contentRu` через `HtmlContentExtractor` в чистый текст → `HarvestedDocument` (Metadata: status/editionId/documentCode). Обычный HTTP, без браузера.
