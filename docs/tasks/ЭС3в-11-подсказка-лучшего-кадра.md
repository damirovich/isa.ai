# ЭС3в-11 — Подсказка лучшего кадра для эталона

**Профиль:** «Следствие» · **Ветка:** `feature/best-frame` · **Дата:** 2026-10-17 · **Статус:** ✔ сделано (ADR-0058)

## Что это

[АИС ФТ-5.7.2]: система оценивает пригодность кадров для биометрии (резкость, поворот головы, освещённость) и
рекомендует лучший образец. Сейчас конвейер считает качество лица и отбраковывает непригодные (ТО-мат-07), но
лучший кадр не предлагает.

## Требования

ТФ-МЕД-21 (новое), ТО-мат-07, ТБ-077, ТФ-ПЕР-01/05.

## Что сделать

- Оценки кадра: резкость, поворот (yaw/pitch по точкам лица детектора), освещённость, размер лица — сохранить при
  индексации (миграция `media`, переиндексация для старых носителей — по кнопке).
- Ранжирование по треку лица в видео и по лицам фото фигуранта; «лучший кадр» с показом оценок.
- В карточке фигуранта и на носителе — «Предложить эталон»: эталоном кадр делает человек (ТБ-077).

## Как проверяется

- Модульные: ранжирование по оценкам, синтетические кадры (без реальных лиц).
- bUnit: подсказка и кнопка.

## Что сделано (ADR-0058)

- Пакет «Медиа»: оценки кадра (`FrameQuality`) — резкость по дисперсии лапласиана области лица (96 пикс.), освещённость
  по средней яркости и контрасту, поворот, кивок и наклон по пяти точкам YuNet (оценка для сравнения кадров), размер
  по межзрачковому расстоянию, итог 0–1 (0 у непригодного лица). Считаются при индексации, сбой оценки индексацию не
  роняет; миграция `media` `FaceFrameMetrics` (7 столбцов `media.face`); старые носители — «Переиндексировать».
- Одно правило ранжирования (`FaceRanking`): пригодные → по оценке кадра → без оценок по общему баллу → по номеру.
- Карточка носителя: лучший кадр трека — по оценке кадра, с оценками словами; «к лучшему кадру»; ★ у лучшего в
  раскрытом треке; у лица фото — его оценки.
- Карточка фигуранта, вкладка «Эталоны»: подсказка лучшего кадра из подтверждённых, не отозванных появлений на
  материалах дела фигуранта (у видео — все кадры трека появления), действующие эталоны не предлагаются, а
  сравниваются; «Сделать эталоном…» открывает окно «Новый эталон» с уже выбранными носителем и лицом — эталоном кадр
  становится только по «Добавить» (ТБ-077).
- Тесты: поза по синтетическим точкам (анфас, поворот, кивок, наклон без ложного поворота), частные оценки и итог,
  ранжирование, подписи, Skia — резкость чёткого выше размытого и тёмное хуже среднего; индексатор пишет оценки и
  переживает сбой оценки; подсказка — только материалы своего дела, весь трек, сравнение с эталоном; bUnit — карточка
  носителя, блок подсказки, окно эталона с выбранным кадром; на Postgres — запись и чтение оценок.

## Зависимости и вопросы

Точки лица YuNet проверены: поворот и кивок по ним — оценка для сравнения кадров между собой, а не измерение угла;
веса и нормировки калибруются на пилоте вместе с порогами ТО-мат-07.
