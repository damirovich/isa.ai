# ЭС3в-11 — Подсказка лучшего кадра для эталона

**Профиль:** «Следствие» · **Ветка:** назначается при старте · **Дата:** 2026-10-17 · **Статус:** ⏳ запланировано

## Что это

[АИС ФТ-5.7.2]: система оценивает пригодность кадров для биометрии (резкость, поворот головы, освещённость) и
рекомендует лучший образец. Сейчас конвейер считает качество лица и отбраковывает непригодные (ТО-мат-07), но
лучший кадр не предлагает.

## Требования

ТФ-МЕД-21 (новое), ТО-мат-07, ТБ-077, ТФ-ПЕР-01/05.

## Что сделать

- Оценки кадра: резкость, поворот (yaw/pitch по точкам лица детектора), освещённость, размер лица — сохранить при
  индексации (миграция `media`, переиндексация для старых носителей — по кнопке).
- Ранжирование по треку лица в видео и по лицам фото фигуранта; «лучший кадр» с показом оценок.
- В карточке фигуранта и на носителе — «Предложить эталон»: эталоном кадр делает человек (ТБ-077).

## Как проверяется

- Модульные: ранжирование по оценкам, синтетические кадры (без реальных лиц).
- bUnit: подсказка и кнопка.

## Зависимости и вопросы

Точки лица (landmarks) YuNet уже есть в детекторе — проверить пригодность для yaw/pitch.
