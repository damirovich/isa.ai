# ЭС3в-09 — Первичное наполнение справочников и АТД КР

**Профиль:** «Следствие» · **Ветка:** назначается при старте · **Дата:** 2026-10-17 · **Статус:** ⏳ запланировано

## Что это

[АИС МГ-8.1]: при развёртывании справочники уже заполнены — оперативно-поисковые подразделения, должности и звания
ГКНБ КР, административно-территориальное деление КР. Справочники профиля есть (ТФ-АДМ-07), но пустые; справочника
АТД нет.

## Требования

ТФ-АДМ-08 (новое), ТФ-АДМ-07, ПОДГ-14, ТО-мат-11, ТФ-МЕД-16; Приложение В вопрос 27.

## Что сделать

- Загрузка справочников из файла (CSV/XLSX) с проверкой, отчётом по строкам и без дублей при повторе — на странице
  «Справочники», с аудитом.
- Новый справочник АТД: область — район или город — айыл аймак — населённый пункт (иерархия, код СОАТЕ).
- Ввод адреса с выбором из АТД и нормализация (ТО-мат-11); место носителя (ТФ-МЕД-16).
- Справочник стран — для гражданства (ЭС3в-03).

## Как проверяется

- Модульные: разбор файла, повторная загрузка без дублей, иерархия АТД.
- Интеграционный: загрузка и выбор адреса из АТД.

## Зависимости и вопросы

Списки — от Заказчика (ПОДГ-14); источник АТД — вопрос 27 (умолчание — СОАТЕ файлом).
