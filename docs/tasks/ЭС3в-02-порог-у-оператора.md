# ЭС3в-02 — Ползунок порога схожести у оператора

**Профиль:** «Следствие» · **Ветка:** назначается при старте · **Дата:** 2026-10-17 · **Статус:** ⏳ запланировано

## Что это

[АИС табл. 2.2 экран 9, В-05, табл. 7.1 № 8]: на панели поиска по лицу — ползунок порога схожести (%). Администратор
задаёт рабочий порог и нижнюю границу (по умолчанию 85 % и 70 %, допустимо 40–99 %), оператор снижает порог не ниже
границы. Сейчас порог и длина списка — только в конфигурации (ТФ-ПЛ-06 ◐).

## Требования

ТФ-ПЛ-08 (новое), ТФ-ПЛ-06, ТФ-АДМ-03 (экран настроек поиска), ТБ-072, Приложение В вопрос 12 (решён).

## Что сделать

- Настройки порога (рабочий, нижняя граница) — в администрировании с аудитом; проверка диапазона 40–99 % с текстом
  отказа по [АИС табл. 7.1 № 8].
- Ползунок на странице поиска по лицу; кандидаты ниже порога не показываются; порог пишется в сессию поиска и аудит.
- Шкала «%» — показ балла модели: функция «балл → %» в одном месте, до калибровки на пилоте (ТО-мат-08) — линейная
  по косинусной близости с пометкой «до калибровки».
- Предустановки «высокий / средний / низкий» (ТФ-ПЛ-06) — значения ползунка.

## Как проверяется

- Модульные: отказ вне 40–99 %; оператор не опускается ниже границы (сервер, не только экран); порог в аудите.
- bUnit: ползунок, подпись «%», пересчёт выдачи.

## Зависимости и вопросы

Калибровка соответствия «балл ↔ %» — ЭС4 (Evals КИ-05..07).
