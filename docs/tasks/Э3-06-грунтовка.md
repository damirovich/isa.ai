# Э3-06. Контракт грунтовки + валидатор

| | |
|---|---|
| Этап | Э3 — Инфраструктурный фундамент |
| Статус | ✅ Выполнено (контракт, валидатор, системный промпт, GATE-2 тест; авто-грунтовка сценариев — Э3-10/Э4) |
| Требования ТЗ | ТБ-040, ТБ-041, ТО-мат-02 (инвариант №1) |
| Документы | [ДОК-05 §2.7](../05_Контракты_и_композиция.md), [ДОК-06 ADR-0005/0008](../06_ADR/README.md) |
| Зависит от | Э3-04, Э3-05 |

## Цель
Реализовать грунтовку как **контракт ядра**: ссылки на НПА — только из извлечённых фрагментов; «по памяти» запрещено.

## Что сделать
- ✅ Контракт валидатора грунтовки в `Abstractions`; реализация `GroundingValidator` в `ISC.AI.AI`.
- ✅ Системный промпт грунтовки в ядре (`GroundingPrompt.SystemRule`), неотключаемый профилем (ТБ-041).
- ✅ Метод строже строкового совпадения: нормализация + сопоставление + проверка `IsCurrent` (базовый; НПА-привязка к норме/редакции — профильные `ICitationExtractor`/`ICitationNormalizer`, калибровка ADR-0008/Э1).
- ⏳ Сквозное pipeline-поведение Mediator — с появлением генерирующих сценариев (Э3-10/Э4); механизм (`IGroundingValidator`) готов.

## Результат
- Контракты [`IGroundingValidator`](../../src/core/ISC.AI.Abstractions/Grounding/IGroundingValidator.cs), `GroundingResult`/`CitationCheck`/`CitationStatus` (Confirmed/Unverified/**Superseded**), доменные швы `ICitationExtractor`/`ICitationNormalizer`.
- [`GroundingValidator`](../../src/core/ISC.AI.AI/Grounding/GroundingValidator.cs): ссылка подтверждается ТОЛЬКО из актуального фрагмента; найденная в неактуальном — `Superseded` (ТЭ-003, ADR-0013); вне фрагментов — `Unverified`. Дефолты `IdentityCitationNormalizer`/`NoCitationExtractor`; профиль переопределяет, но не ослабляет инвариант (ТБ-041). `GroundingPrompt.SystemRule` — ядровое неотключаемое правило. Регистрация `AddCoreGrounding` в хосте.
- Тесты GATE-2: [`GroundingValidatorTests`](../../tests/ISC.AI.UnitTests/Grounding/GroundingValidatorTests.cs) — Confirmed / Unverified / Superseded / нет ссылок. Сборка 0/0; unit 17/17.

## Осталось
- Авто-грунтовка генерирующих сценариев (pipeline-поведение Mediator) — Э3-10/Э4.
- Профильные `ICitationExtractor`/`ICitationNormalizer` для НПА (ru/ky) + калибровка порогов — ADR-0008, Э1, метрика КИ-01.

## Критерии приёмки
- **GATE-2**: вывод с неподтверждённой ссылкой не выдаётся как готовый — помечается непроверенным.
