# Э3-06. Контракт грунтовки + валидатор

| | |
|---|---|
| Этап | Э3 — Инфраструктурный фундамент |
| Статус | ⏳ Запланировано |
| Требования ТЗ | ТБ-040, ТБ-041, ТО-мат-02 (инвариант №1) |
| Документы | [ДОК-05 §2.7](../05_Контракты_и_композиция.md), [ДОК-06 ADR-0005/0008](../06_ADR/README.md) |
| Зависит от | Э3-04, Э3-05 |

## Цель
Реализовать грунтовку как **контракт ядра**: ссылки на НПА — только из извлечённых фрагментов; «по памяти» запрещено.

## Что сделать
- ⏳ Контракт валидатора грунтовки в `Abstractions`; реализация в `ISC.AI.AI`.
- ⏳ Системный промпт грунтовки в ядре, неотключаемый профилем (ТБ-041).
- ⏳ Метод строже строкового совпадения (нормализация цитат, привязка к норме/редакции, ТО-мат-02 → ADR-0008).
- ⏳ Сквозное pipeline-поведение Mediator: проверка грунтовки на каждом генерирующем сценарии.

## Критерии приёмки
- **GATE-2**: вывод с неподтверждённой ссылкой не выдаётся как готовый — помечается непроверенным.
