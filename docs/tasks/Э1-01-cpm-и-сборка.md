## Цель
Единое централизованное управление версиями пакетов и сборочная конфигурация; подготовка офлайн-поставки для изолированного контура.

## Что сделать
- ✅ `Directory.Packages.props` (CPM) — все версии пинятся централизованно, только MIT/Apache.
- ✅ `Directory.Build.props` — общие свойства (net10.0, nullable, анализаторы).
- ✅ `tests/Directory.Build.props` — общая тестовая обвязка.
- ⏳ `nuget.config` — ограничить источники единственным **внутренним офлайн-фидом** (ТБ-050).
- ⏳ Регламент контролируемого переноса пакетов/весов моделей за периметр с проверкой целостности (ТБ-051).

## Критерии приёмки
- `dotnet restore`/`build` проходят; версии заданы только в CPM.
- (Офлайн) восстановление возможно из внутреннего фида без доступа в интернет.

## Результат
- `Directory.Packages.props`, `Directory.Build.props`, `tests/Directory.Build.props` (в git).
