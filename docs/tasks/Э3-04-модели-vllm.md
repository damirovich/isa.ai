## Цель
Подключить локальные модели через нейтральный `IChatClient` (Microsoft.Extensions.AI) к vLLM по keyed-ролям.

## Что сделать
- ⏳ Адаптер к vLLM (OpenAI-совместимый) в `ISC.AI.AI`; keyed-регистрация `draft`/`analysis`/`embeddings` через `IModelContributor`.
- ⏳ `IEmbeddingGenerator` для ru/ky; выбор модели эмбеддингов — бенчмарк (ADR-0011).
- ⏳ Защита канала «хост ↔ vLLM» (внутренний интерфейс, без внешнего доступа, ТБ-044).
- ⏳ Стриминг длинных вызовов через `IAsyncEnumerable` + `CancellationToken`.

## Критерии приёмки
- Ядро не знает названий моделей; клиент разрешается по ключу-роли; обращения только внутри контура.
