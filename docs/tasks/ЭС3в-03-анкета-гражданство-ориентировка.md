# ЭС3в-03 — Анкета: гражданство и ориентировка

**Профиль:** «Следствие» · **Ветка:** назначается при старте · **Дата:** 2026-10-17 · **Статус:** ⏳ запланировано

## Что это

[АИС ФТ-5.1.3, табл. 2.1 п. 2, табл. 2.3]: в анкете объекта есть «гражданство» и «ориентировка (сведения) об
объекте». У нас таких полей нет: перенос из Access кладёт гражданство и сведения об объекте в примечание.

## Требования

ТФ-ПЕР-13 (новое), ТФ-ПЕР-05, ТФ-ДЕЛ-07 (перенос Access), ТФ-ОТЧ-01, ТФ-ПСК-01.

## Что сделать

- Поля анкеты: гражданство (справочник стран + своё значение), ориентировка — текстовый блок; миграция `investigation`.
- Карточка фигуранта, справка по фигуранту (ADR-0053), точный поиск по гражданству.
- Перенос из Access (ADR-0043): «гражданство» и «сведения об объекте» — в новые поля.
- Предупреждение при фото анкеты меньше 300×400 пикселей [АИС табл. 7.1 № 2] — фото принимается.

## Как проверяется

- Модульные: валидатор, перенос Access кладёт значения в поля; интеграционный — хранилище и поиск.
- bUnit: блок анкеты, предупреждение о размере фото.

## Зависимости и вопросы

Справочник стран — первичное наполнение (ЭС3в-09).
