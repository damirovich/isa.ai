## Цель
Дать инспектору семантический поиск по корпусу НПА (по смыслу) с учётом допуска и статуса редакции.

## Что сделать
- ✅ Use-case запроса (Mediator `SearchNpaQuery`) поверх ядрового `IRetriever`; аудит обращения (`Search`, ТБ-030).
- ✅ Страница модуля «База НПА» в `*.UI` (MudBlazor): поле запроса, результаты с источником (документ) и релевантностью; зарегистрирована в реестре модулей.
- ✅ Только действующие редакции по умолчанию (GATE-3 в ретривере); пометка «УТРАТИЛА СИЛУ» в UI (для показа устаревших).

## Критерии приёмки
- Поиск возвращает релевантные фрагменты в пределах допуска (GATE-1); утратившие силу не выдаются как действующие (GATE-3).
