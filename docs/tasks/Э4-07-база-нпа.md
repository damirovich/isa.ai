## Цель
Дать инспектору семантический поиск по корпусу НПА (по смыслу) с учётом допуска и статуса редакции.

## Что сделать
- ⏳ Use-case запроса (Mediator) поверх `IRetriever`.
- ⏳ Страница модуля «База НПА» в `*.UI` (MudBlazor): поле запроса, результаты с источниками.
- ⏳ Только действующие редакции по умолчанию; пометка «УТРАТИЛА СИЛУ».

## Критерии приёмки
- Поиск возвращает релевантные фрагменты в пределах допуска (GATE-1); утратившие силу не выдаются как действующие (GATE-3).
