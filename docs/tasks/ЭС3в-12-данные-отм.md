# ЭС3в-12 — Технические данные ОТМ: биллинги, базовые станции, технические логи

**Профиль:** «Следствие» · **Ветка:** назначается при старте · **Дата:** 2026-10-17 · **Статус:** 👤 ждёт образцов
Заказчика (вопрос 25), затем ⏳

## Что это

[АИС 1.3, В-06, экран 5]: группа ОТМ работает с биллингами базовых станций и аппаратно-техническими логами; в
сводке ОН есть поле «базовые станции». В системе этого нет. Новый модуль профиля «Технические данные ОТМ» (§5.2.11).

## Требования

ТФ-ОТМ-01 (приём биллингов), ТФ-ОТМ-02 (справочник базовых станций, поле в сводке ОН), ТФ-ОТМ-03 (анализ
соединений), ТФ-ОТМ-04 (технические логи, P2); ТС-014, GATE-7, ТБ-024, ТБ-077, ТБ-084; Приложение В вопрос 25.

## Что сделать

- Получить обезличенные образцы биллингов, выгрузок БС и логов (вопрос 25); до образцов — только ТФ-ОТМ-04
  (прикрепление файлов к делу ОТМ).
- Приём биллинга: файл с SHA-256 в хранилище, сопоставление столбцов на экране (по образцу переноса Access,
  ADR-0043), проверка до загрузки, повтор без дублей, гриф и подразделение подтверждает оператор.
- Справочник базовых станций (код, сектор, адрес, координаты, азимут); поле «базовая станция» в событии сводки ОН.
- Анализ: соединения номера за период, частые и общие контакты, станции на дату и время; связь номера с объектом по
  телефону (ЭС3в-04) — подсказкой.
- Только дела ОТМ и только при допуске к ним (ТС-014, GATE-7). ADR модуля.

## Как проверяется

- Интеграционные: GATE-7 — сотрудник без допуска ОТМ не видит ни записей, ни факта; повтор загрузки без дублей.
- Модульные: разбор строк по сопоставлению, нормализация номеров.

## Зависимости и вопросы

Вопрос 25 (образцы), ЭС3в-04 (номера телефонов).
