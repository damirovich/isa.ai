# ЭС3в-04 — Номера телефонов и пересечение по номеру

**Профиль:** «Следствие» · **Ветка:** `feature/questionnaire-phones` · **Дата:** 2026-10-17 · **Статус:** ✔ сделано
(ADR-0055)

## Что это

[АИС В-02]: пересечения ищутся и по номеру телефона. У объекта и связи сейчас нет телефонов; пересечения — по
госномеру, адресу, ФИО с датой рождения и лицу (ТФ-ПЕР-07, ADR-0029).

## Требования

ТФ-ПЕР-12 (новое), ТФ-ПЕР-07, ТО-мат-11, ТБ-084, GATE-7, ТФ-ПСК-01; связь с ТФ-ОТМ-03.

## Что сделать

- Список номеров у фигуранта (вид, примечание), исходное и нормализованное значение (только цифры, 996 для местных);
  миграция `investigation`, гриф строки — как у адресов и транспорта.
- Пятый вид пересечения «телефон» в хранилище пересечений и графе (ADR-0045); подтверждение / отклонение — как у
  остальных видов.
- Точный поиск по номеру в едином поиске (ADR-0048).
- Справка по фигуранту и перенос из Access (если в базе будет столбец телефона).

## Как проверяется

- Модульные: нормализация номеров (разные записи одного номера совпадают).
- Интеграционные: пересечение по номеру под решёткой; GATE-7 — номер из дела выше допуска не раскрывается.

## Что сделано (ADR-0055)

- Таблица `investigation.person_phone` (миграция `QuestionnaireAndPhones`): вид (мобильный / домашний / рабочий / иной),
  номер как введён, нормализованный номер (ограничение таблицы — только цифры), примечание; гриф и подразделение —
  фигуранта (ТБ-070); каскадное удаление с фигурантом и делом.
- Нормализация (`RequisiteNormalizer.Phone`): только цифры; «00» в начале снимается; 10 цифр с «0» → «996» + 9 цифр;
  9 цифр → «996» + номер; иное — как есть. «0555 123 456», «+996 555 12-34-56», «555 123 456» — один номер.
- Карточка фигуранта (и связи): вкладка «Адреса, транспорт, телефоны» — таблица номеров, добавить / изменить / удалить;
  ведут роли, ведущие дела; в журнале — без номера (ТБ-032).
- Пятый вид пересечения «Телефон» (ADR-0029) — по точному номеру, чужая сторона под floor и политикой (ТБ-084, GATE-7);
  подтверждение / отклонение — как у остальных видов.
- Граф связей: узел «телефон» (один на номер), раскрытие — доступные фигуранты с тем же номером; пересечение — ребром от
  узла номера.
- Единый поиск: вид «Телефоны» — запрос из цифр и «+ - ( ) .» от 5 цифр (не дата) ищется по нормализованному номеру,
  целиком или частью. Справка по фигуранту — раздел «Телефоны»; корпус чата — номера в сведениях дела.
- Перенос из Access: столбца телефона объекта или связи в реальной базе нет — не переносится (телефон инициатора —
  реквизит задания, как прежде).
- Тесты: нормализация, разбор запроса, команды и валидатор, граф, единый поиск, справка, страница поиска (bUnit); на
  Postgres — хранилище под решёткой, ограничение таблицы, уничтожение дела, пересечение и владельцы номера с GATE-7.

## Зависимости и вопросы

Форматы номеров в материалах Заказчика — на обследовании (иностранные номера без «+» и кода хранятся цифрами как есть);
биллинги ОТМ — ЭС3в-12.
