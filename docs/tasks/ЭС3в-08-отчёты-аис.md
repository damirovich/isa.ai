# ЭС3в-08 — Отчёты по утверждённому ТЗ: суточная активность, граф связей, результативность распознавания

**Профиль:** «Следствие» · **Ветка:** `feature/ais-reports` · **Дата:** 2026-10-17 · **Статус:** ◐ часть 1 из 4 (ADR-0061)

## Что это

[АИС 6.0, 6.3–6.5]: три формы отчётов, которых у нас нет, и статистика созданных карточек по подразделениям-
инициаторам. Сейчас есть отчёты только по документам документооборота и справки по делу и фигуранту (ADR-0053).

## Требования

ТФ-ОТЧ-05 (журнал суточной оперативной активности), ТФ-ОТЧ-06 (отчёт по графу связей), ТФ-ОТЧ-07 (результативность
распознавания), ТФ-ОТЧ-04 (статистика карточек по ГУ-инициаторам), ТБ-033, ТБ-084, ОР-6.0.3.

## Что сделать

- Журнал суточной активности: период, группа ОН/ОУ/ОТМ (в пределах допуска); колонки по [АИС 6.3]; .docx/.xlsx.
- Отчёт по графу: исходный объект, дела, объекты 1-го порядка, цепочки 2–3 порядка, пересечения по транспорту и
  местам — тем же обходом, что граф (ADR-0045), с ТБ-084; .docx с грифом.
- Результативность распознавания: обработано, лиц, отклонено по качеству, совпадений выше порога, подтверждено и
  отклонено — из записей и аудита, без ИИ; по подразделениям за период.
- Статистика карточек объектов по ГУ-инициаторам — в количественных отчётах (ТФ-ОТЧ-04).
- Каждая выгрузка — запись «Выгрузка» в журнале; гриф файла — максимум по вошедшему.

## Как проверяется

- Интеграционные на настоящем Postgres: счётчики сходятся с первичными записями [ОР-6.0.2]; данные вне допуска не
  попадают; гриф файла.

## Что сделано — часть 1: результативность распознавания (ADR-0061)

- Пакет «Медиа»: порт `IMediaStatistics` — счёт по подразделениям за период под той же решёткой, что каталог: фото и
  видео, проиндексированные в периоде; их лица и непригодные по качеству; сессии поиска периода (автосверки отдельно);
  кандидаты выдачи этих сессий по статусам верификации. Кандидат входит, только если видна и его сессия. Гриф — максимум
  вошедших записей.
- Профиль: раздел меню «Отчётность» → «Результативность распознавания» (`/reports/recognition`): период (по умолчанию —
  текущий месяц), подразделение из разрешённых, таблица с итогом, гриф отчёта; выгрузка Excel/Word/PDF отрисовщиками
  документооборота — маркировка грифа, «Сформировал», отбор; запись «Выгрузка» до выдачи файла. Право «Статистические
  отчёты» (Руководитель, Администратор, Офицер ИБ).
- Тесты: на Postgres — счётчики сходятся с засеянными записями, вне периода, подразделения и грифа — не в счёт, гриф;
  модульные — наименования с отделом, период → UTC, ячейки и доли, представление выгрузки, право, журнал выгрузки,
  правила; bUnit — страница и выгрузка.

## Зависимости и вопросы

Цепочки через события — после ЭС3в-05; общие показатели с ТФ-ВЕР-05 и ТФ-ОТЧ-03 — одним расчётом.
