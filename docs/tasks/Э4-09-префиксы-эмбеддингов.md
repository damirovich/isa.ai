## Контекст
Справочник заказчика по EmbeddingGemma (§3 «Префиксы задач — критично», §12 «Префиксы — не опционально») требует **task-специфичных префиксов**: модель кодирует **запрос** и **документ** по-разному (асимметрично), и **без префиксов retrieval заметно хуже** — это «самый частый источник плохого поиска».

Сейчас платформа эмбедит **сырой текст** без префиксов в обоих местах:
- `PgVectorRetriever` — эмбеддинг **запроса** без префикса;
- `IngestionPort` — эмбеддинг **чанков** без префикса.

Это снижает релевантность выдачи (отдельно от уже исправленного фильтра доступа GATE-1, который влиял на **количество**, а не качество).

## Цель
Добавить task-префиксы EmbeddingGemma при эмбеддинге запроса и чанков, подняв качество семантического поиска и КИ-03 (recall).

## Что сделать
- ✅ Хелпер префиксов в ядре (нейтрально к домену, EmbeddingGemma-специфично — ADR-0011):
  - запрос → `task: search result | query: {text}`;
  - документ/чанк → `title: none | text: {text}`.
- ✅ `PgVectorRetriever`: оборачивать запрос query-префиксом перед эмбеддингом.
- ✅ `IngestionPort`: оборачивать каждый чанк document-префиксом перед эмбеддингом (порядок/батч сохраняются).
- ✅ Юнит-тест формата префиксов.

## Критерии приёмки
- ✅ Запрос эмбедится с query-префиксом, чанк — с document-префиксом (одна и та же модель/сервер для обоих).
- ✅ Сборка зелёная; существующие тесты не падают (unit 57/57).

## Результат
- [`EmbeddingTaskPrompt`](../../src/core/ISC.AI.Abstractions/AI/EmbeddingTaskPrompt.cs) — статический хелпер в `Abstractions/AI`: `Query(text)` / `Document(text)`. Обе сборки ядра (`AI`, `Ingestion`) уже ссылаются на `Abstractions`, доменной связи не добавляет.
- [`PgVectorRetriever`](../../src/core/ISC.AI.AI/Retrieval/PgVectorRetriever.cs): запрос → `EmbeddingTaskPrompt.Query(query)` перед эмбеддингом.
- [`IngestionPort`](../../src/core/ISC.AI.Ingestion/IngestionPort.cs): каждый чанк → `EmbeddingTaskPrompt.Document(...)`, порядок входов = порядок чанков.
- Тест [`EmbeddingTaskPromptTests`](../../tests/ISC.AI.UnitTests/Ai/EmbeddingTaskPromptTests.cs) (3 кейса: query-префикс, document-префикс, их различие).

## Осталось / риски
- ⚠️ **Переиндексация обязательна.** Смена префиксов меняет векторы: уже загруженный корпус (эмбеженный без document-префикса) рассогласован с запросами (с query-префиксом). После внедрения — **перезагрузить корпус** (re-embed).
- Префиксы EmbeddingGemma-специфичны (ADR-0011); при смене эмбеддера — пересмотреть (вынести за абстракцию/конфиг).
- Гибридный поиск (vector + BM25) для смешанных ru/ky запросов — отдельное улучшение после MVP (см. справочник §10).
