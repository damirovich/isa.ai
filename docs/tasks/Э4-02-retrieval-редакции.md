## Цель
Извлекать релевантные фрагменты с учётом допуска и статуса редакции (по умолчанию — только действующие).

## Что сделать
- ⏳ Применить `IRetriever` в сценариях; фильтр доступа (fail-closed) + фильтр по статусу редакции.
- ⏳ Пометка «УТРАТИЛА СИЛУ» при явном показе устаревших редакций (ТЭ-003).

## Критерии приёмки
- **GATE-3**: утратившая силу не выдаётся как действующая; пользователь не получает материалы выше допуска (GATE-1).
