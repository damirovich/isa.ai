## Цель
Подключить векторное хранилище pgvector в той же БД и индекс для семантического поиска.

## Что сделать
- ⏳ `CREATE EXTENSION vector` в bootstrap-миграции.
- ⏳ Колонка `vector(N)` в таблице эмбеддингов; ANN-индекс.
- ⏳ Стратегия фильтрации векторного поиска по грифу (pre/post-filter) — обосновать в ADR-0007 (ТБ-022).

## Критерии приёмки
- Векторный поиск работает на Testcontainers (Postgres+pgvector); фильтр по грифу применяется на стороне БД.
