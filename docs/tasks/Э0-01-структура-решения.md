## Цель
Собрать каркас решения из 14 проектов со структурой и графом зависимостей по целевой архитектуре.

## Что сделать
- Создать проекты ядра: `Abstractions`, `AI`, `Ingestion`, `Documents`, `Persistence`, `Web`.
- Создать проекты профиля: `Inspector`, `.Domain`, `.Application`, `.Data`, `.UI`.
- Создать тестовые проекты: `UnitTests`, `IntegrationTests`, `Evals`.
- Проставить ссылки между проектами по правилу зависимостей.

## Критерии приёмки
- Решение `ISC.AI.slnx` содержит 14 проектов на `net10.0`.
- `dotnet build` проходит без ошибок.

## Результат
- 14 проектов в `src/core`, `src/profiles/inspector`, `tests` (зафиксировано в git).
