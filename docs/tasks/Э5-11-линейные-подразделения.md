# Э5-11 — Линейные подразделения: заглушка снята

**Ветка:** `feature/linear-divisions` · **Дата:** 2026-08-25 · **Статус:** готово

## Что это

Страница «Линейные» (`/divisions/linear`) была последней заглушкой интерфейса («модель данных
готова, нужен справочник»). После появления `DivisionKind` (Э5-10) справочник стал возможен:
разметка и логика страницы «Территориальные» вынесены в общий компонент
`Components/DivisionDirectory.razor` с параметром типа, обе страницы — тонкие обёртки над ним.

- Каждая страница показывает и создаёт подразделения ТОЛЬКО своего типа; родитель выбирается
  внутри типа (иерархия не пересекает типы).
- Правка позволяет сменить тип — запись честно переезжает на соседнюю страницу (без дублей:
  таблица `inspector.division` одна, страницы лишь фильтруют).
- Колонка «Тип» со страницы убрана (тип задан страницей); выбор типа при создании больше не нужен.
- Разрез «территориальные/линейные» кормит аналитику архива (ТФ-АРХ-03): пока линейные
  не помечены/не заведены, факт-блок честно объявляет сравнение невозможным.

## Итог

Заглушек в интерфейсе не осталось совсем — ни модульных (§5.2 закрыт в Э5-09), ни служебных.
