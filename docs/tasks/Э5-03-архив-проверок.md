# Э5-03 — Архив проверок (§5.2.4)

**Ветка:** `feature/inspection-archive` · **Дата:** 2026-08-24 · **Статус:** готово (P1-объём)

## Что это

История проверок и нарушений по подразделениям (ТФ-АРХ-01) с отбором по любому параметру
(ТФ-АРХ-02): подразделение, сфера/вид, тяжесть, статус устранения, период, № справки.
ИИ-аналитика архива (ТФ-АРХ-03) — P2, не входит.

Единица истории — **группа «справка-проверка × подразделение»**: нарушения, у которых заполнено
поле «Справка-проверка (№)» (`Violation.ReferenceDocRef`, слабая ссылка по значению RegNumber,
ТО-инф-06), собираются под своей справкой; нарушения без справки не теряются — образуют группу
«вне проверок» своего подразделения.

## Устройство

- **Порт документооборота `IDocumentLookup`** (DocFlow.Domain → реализация `DocumentLookup` в
  DocFlow.Data, регистрация в `AddDocFlowPersistence`): разрешение партии RegNumber → карточки
  документов. **Решётка доступа — В ЗАПРОСЕ** тем же предикатом `AccessFilterExtensions.VisibleTo`,
  что список документов (ТБ-020/021): недоступный документ в ответе отсутствует, порт не
  становится обходным каналом чтения метаданных. Партия ≤ 200.
- **Профиль**: `IInspectionArchiveStore`/`InspectionArchiveStore` — группирующий запрос по
  `inspector.violation` (заголовки групп агрегатами SQL, строки — добором по ссылкам/подразделениям
  страницы, точные пары в памяти); отбор применяется и к заголовкам, и к строкам.
  `IInspectionDocumentResolver`/`InspectionDocumentResolver` (Inspector.Data — единственное место
  кросс-модульной склейки): порт модуля + `IAccessContextProvider` (fail-closed) + имена
  инспекторов из реестра пользователей ядра одним запросом.
- **Сценарий** `ListInspectionArchiveQuery` (Search-аудит): страница групп + карточки справок;
  недоступная справка остаётся голым номером — как её и ввели в нарушении.
- **UI** `/archive`: фильтры, карточки «Справка № … · подразделение» с метаданными документа
  (тип, дата, инспектор, статус исполнения) и нарушениями внутри; заглушка ModuleStub снята.
- Поле карточки нарушения переименовано: «Нарушенная норма (НПА)» → **«Справка-проверка (№)»** —
  подпись расходилась с доменной семантикой `ReferenceDocRef`.

## Тесты

- `InspectionArchiveTests` — группировка «справка × подразделение», «вне проверок», порядок
  «свежие первыми», отбор влияет на заголовки И строки, экранирование LIKE в поиске номера,
  счёт групп до среза.
- `DocumentLookupTests` — разрешение номеров не отдаёт документы выше допуска/чужого
  подразделения; несуществующий номер отсутствует, а не падает.
- `InspectionArchiveHandlerTests` (юнит) — недоступная справка остаётся голым номером,
  резолверу уходят только непустые номера без дублей.

## Не входит (по потребности)

- Автоподстановка номера справки из документооборота при занесении нарушения (шаг 5 Э5-01).
- Переход из карточки архива в документ документооборота (ссылка на /docflow/documents/{id}).
- ИИ-аналитика трендов и сравнение подразделений (ТФ-АРХ-03, P2).
