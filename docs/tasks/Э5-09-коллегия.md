# Э5-09 — Коллегия (§5.2.8, ТФ-КОЛ-01/02)

**Ветка:** `feature/collegium` (поверх `feature/meetings`) · **Дата:** 2026-08-25 · **Статус:** готово

## Что это

Модуль «Коллегия» (заглушка снята — последняя: все модули §5.2 реализованы). Три вида материалов
к заседанию коллегии и совещанию руководства, каждый — своим промпт-шаблоном на ОДНОМ факт-блоке:

- **Доклад на заседание коллегии** (ТФ-КОЛ-01): состояние контроля, оценка подразделений,
  системные проблемы, предложения коллегии.
- **Проект решения коллегии** (ТФ-КОЛ-01): констатирующая часть + пронумерованные поручения;
  календарные сроки ИИ НЕ назначает — оставляет «в срок до ______» для человека.
- **Материалы к совещанию руководства** (ТФ-КОЛ-02): повестка, ключевые цифры, тезисы
  по подразделениям, вопросы к решению.

**Разделение труда:** факт-блок ОБЩИЙ с отчётом руководству (`ManagementReportFacts.Build`
из `IRiskDataSource` — те же числа, что на экранах Рисков/Мониторинга); ИИ быстрой ролью Draft
пишет только связующий текст под структуру выбранного вида. Результат — проект (ТБ-042).

## Судьба материала

Как у всех ИИ-документов: документный лист с гербом, экспорт в .docx (гриф — ТБ-033),
«Доработать в Редакторе», «Зарегистрировать в документообороте» (пометка «сформировано ИИ
(Коллегия)», GATE-2-гейт на неподтверждённые ссылки).

## Устройство

- Шаблоны `Generation/Prompts/collegium-report|decision|briefing.scriban` (параметры
  `period_days`, `facts`).
- `GenerateCollegiumMaterialCommand(Kind, PeriodDays)` — `IGroundedScenario`, роль Draft,
  guard пустого ответа; аудит пишет оркестратор ядра. Все три шаблона парсятся при создании
  обработчика — опечатка в имени ресурса всплывает на первом обращении к модулю.
- UI `Pages/Collegium.razor`: выбор вида и периода, результат в `DocumentSheet`; заголовок листа
  фиксируется на момент генерации (перещёлкивание селектов после — не меняет).
- Тесты `CollegiumMaterialTests`: каждый вид берёт СВОЙ встроенный шаблон (заголовок вида
  в промпте), факт-блок и запрет чисел в промпте, роль Draft, HITL; проект решения запрещает
  выдуманные сроки.

## Не входит

- Хранилище материалов — не нужно: судьба решается регистрацией в документообороте.
- Автосборка «папки к заседанию» из нескольких материалов разом — по потребности.
