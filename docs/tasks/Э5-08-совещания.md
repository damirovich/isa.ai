# Э5-08 — Совещания (§5.2.7, ТФ-СОВ-01/02)

**Ветка:** `feature/meetings` · **Дата:** 2026-08-25 · **Статус:** готово

## Что это

Модуль «Совещания» (заглушка снята). Ключевое решение: протокол совещания — это ДОКУМЕНТ группы
«Исполнение» документооборота, а пункты протокола — его назначения. Вся механика контроля
(сроки, статусы, продления, автопросрочка, уведомления) уже живёт в документообороте — модуль её
не дублирует, а показывает под углом «протокол → пункты» и добавляет генерацию справки.

- **ТФ-СОВ-01 (учёт):** реестр протоколов с отбором по типу (справочник типов группы «Исполнение»,
  подсказка завести тип «Протокол совещания»), карточка пунктов: подразделение, срок, статус чипом.
  Регистрация протокола — штатной формой документооборота (`/docflow/documents/new`).
- **ТФ-СОВ-02 (справка об исполнении):** состояние пунктов считает КОД (`MeetingReportFacts.Build` —
  счётчики исполнено/в работе/просрочено, построчно по пунктам, пометка «ТРЕБУЕТ ЭСКАЛАЦИИ»
  у просроченных); ИИ быстрой ролью Draft пишет только связующий текст (разделы ОБЩИЙ ИТОГ /
  ПО ПУНКТАМ / ЭСКАЛАЦИЯ / ПРЕДЛОЖЕНИЯ). Результат — проект для человека (ТБ-042).

## Судьба справки

Как у всех ИИ-документов: документный лист с гербом (`DocumentSheet`), экспорт в .docx (гриф,
общий экспортёр — ТБ-033), «Доработать в Редакторе», «Зарегистрировать в документообороте»
(пометка «сформировано ИИ (Совещания)», GATE-2-гейт на неподтверждённые ссылки).

## Устройство

- Контракт `IMeetingProtocolReader` (`Inspector.Domain`) + реализация `MeetingProtocolReader`
  (`Inspector.Data`): читает документ через `IDocumentStore.GetAsync` ОТ ИМЕНИ субъекта (решётка —
  в документообороте), имена подразделений — из справочника профиля одним запросом; недоступный
  протокол неотличим от несуществующего (NotFound).
- Шаблон `Generation/Prompts/meeting-report.scriban` (параметр `facts`).
- `GenerateMeetingReportCommand(DocumentId)` — `IGroundedScenario`, роль Draft, guard пустого
  ответа; аудит пишет оркестратор ядра. Гриф справки = max(гриф ответа, гриф протокола):
  факты пришли из режимного документа, наследование обязательно (ТБ-033).
- UI `Pages/Meetings.razor`: docflow-запросы через общий Mediator (`ListDocumentTypesQuery`,
  `ListDocumentsQuery`, `GetDocumentQuery` — View-аудит уже в нём, `ListDivisionsQuery` — имена
  подразделений тем же приёмом, что карточка документа).
- Тесты `MeetingReportTests`: факт-блок несёт счётчики/сроки/эскалацию, пустой протокол честно
  назван; настоящий шаблон встроен; handler шлёт роль Draft с факт-блоком; гриф наследуется;
  недоступный протокол — NotFound без вызова модели.

## Не входит

- Отдельное хранилище справок — не нужно: судьба справки решается регистрацией в документообороте.
- «Коллегия» (§5.2.8, ТФ-КОЛ-01/02) — следующая задача, отдельная ветка.
