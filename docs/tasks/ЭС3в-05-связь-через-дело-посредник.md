# ЭС3в-05 — Связь двух объектов через дело-посредник

**Профиль:** «Следствие» · **Ветка:** назначается при старте · **Дата:** 2026-10-17 · **Статус:** ⏳ запланировано

## Что это

[АИС ФТ-5.2.1, 5.2.4–5.2.7, табл. 2.3, ПМИ 3–5]: модель «Объект — Дело — Объект». Сотрудник связывает два
существующих объекта (из разных заданий) через дело-посредник — событие (встреча, контакт, поездка) — с ролью,
транспортом, адресом контакта, **уровнем связи** «верно / предположительно / неверно» и отметкой «учитывать в общем
поиске». Сейчас связи живут внутри одного дела (фигурант-связь), а между делами — только автоматические пересечения.

## Требования

ТФ-ПЕР-11 (новое), ТФ-ПЕР-10 (граф), ТФ-ОТЧ-06, ТБ-073, ТБ-084, ТБ-030; Приложение В вопрос 26.

## Что сделать

- ADR: форма хранения события (умолчание вопроса 26 — событие на связи двух объектов, гриф не ниже грифов обоих,
  подразделение — того, кто заводит), видимость по ТБ-084, удаление и уничтожение дела (ADR-0025).
- Схема `investigation`: событие и участники (объект, роль, транспорт, адрес, уровень связи, «в общем поиске»);
  запрет связи объекта с самим собой [АИС табл. 7.1 № 3].
- Карточка объекта: блок «Связи через события», диалог связывания (выбор объекта в пределах допуска).
- Граф (ADR-0045): ребро «объект — событие — объект», выборка по событию — все участники [ФТ-5.2.5], «Как связан
  с…» через события, без зацикливания [ФТ-5.2.6/5.2.7].
- Аудит заведения, правки и удаления связи.

## Как проверяется

- Модульные: самосвязь — отказ; уровни связи; отметка «в общем поиске».
- Интеграционные: связь видна в обеих карточках; объект выше допуска не выбирается и не раскрывается (ТБ-084);
  цепочка 2-го порядка «Объект 2 → Дело 2 → Объект 3 → Дело 3 → Объект 4» [ПМИ 4]; кольцо без зависания [ПМИ 5].

## Зависимости и вопросы

Вопрос 26 Приложения В (до ответа — умолчание). Отчёт по графу — ЭС3в-08.
