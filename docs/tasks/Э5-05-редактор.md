# Э5-05 — Редактор (§5.2.10, ТФ-РЕД-01..03)

**Ветка:** `feature/editor` · **Дата:** 2026-08-24 · **Статус:** готово (P1-объём)

## Что это

ИИ-правка документов по команде инспектора (ТФ-РЕД-02): «переформулируй строже», «приведи
к деловому стандарту», «сократи», «добавь норму про …» — свободным текстом или подсказками.
Третий генерирующий сценарий на конвейере Генератора (после справки и методик) — ядро и грунтовка
не трогались.

**Ключевой инвариант — грунтовка СОХРАНЯЕТСЯ при правке:** модель возвращает новую редакцию
целиком, и она проходит валидатор ссылок как обычная генерация (GATE-2). Правка не может протащить
выдуманную норму: добавленная ссылка либо подтверждается извлечёнными фрагментами, либо помечается
красным, и редакция «не считается готовой». Если нормы по команде во фрагментах нет — модель
обязана прямо написать «норма не найдена», а не сочинить реквизиты (требование в задачном промпте).

## Устройство

- **Шаблон** `Generation/Prompts/editor.scriban`: параметры `instruction`/`document`; требования —
  менять только то, чего касается команда, остальной текст дословно; ссылки только из фрагментов;
  ответ — только новая редакция без комментариев.
- **Рендерер** `IEditorPromptRenderer`/`ScribanEditorPromptRenderer` (ключ «editor»); DI —
  `AddInspectorApplication`.
- **Команда** `ReviseDocumentCommand(Text, Instruction)` (`IGroundedScenario`, НЕ `IAuditableRequest`
  — аудит пишет оркестратор ядра). Тема ИЗВЛЕЧЕНИЯ — команда + первые 300 символов документа
  (контекст темы), не документ целиком. Конверт — общий `GenerateReferenceResult`.
  Валидатор: текст ≤100 000, команда ≤500, оба обязательны.
- **UI** `/editor` (заглушка снята, модуль перенесён в реализованные): слева документ (вставленный
  или набранный) и команда с подсказками; справа предложенная редакция с метками грунтовки и
  кнопками «Принять — заменить текст» (итеративная доработка: принял → следующая команда) /
  «Отклонить» / «Экспорт редакции в .docx» (ТФ-РЕД-03 — общий экспортёр, гриф результата, ТБ-033).
  Принимает правку ЧЕЛОВЕК (ТБ-042).

## Тесты

`EditorRevisionTests` (юнит): настоящий шаблон «editor» встроен и рендерит команду с документом
(заголовок-комментарий и подстановки не протекают); handler строит тему извлечения из команды и
НАЧАЛА документа (длинный текст усечён), задачный промпт — из рендерера, результат всегда HITL;
валидатор требует и текст, и команду.

## Регистрация в документообороте (добавлена тем же днём, решение заказчика)

На результате Генератора и Редактора — кнопка «Зарегистрировать в документообороте»
(общий диалог `RegisterGeneratedDialog`): тип документа, подразделение-владелец, рег. номер,
дата, краткое содержание; документ создаётся штатной командой модуля `RegisterDocumentCommand`
(гриф — унаследован от генерации; направленность — внутренний). Сформированное перестаёт
пропадать: живёт в реестре документов со всеми режимными атрибутами, а его номер, вписанный
в нарушение («Справка-проверка №»), связывает его с Архивом проверок.

- **ЧЕСТНОСТЬ (ТБ-042):** ИИ-происхождение помечено в поле «Источник» («ИнспекторAI · сформировано
  ИИ (Генератор|Редактор)») и в примечании (`GeneratedDocumentStamp`: кем/когда сформирован,
  принят человеком, итог грунтовки) — тест `GeneratedDocumentStampTests`.
- **GATE-2 на регистрацию:** кнопка активна ТОЛЬКО при полностью подтверждённой грунтовке.
  Регистрация запускает штатную индексацию документа в поисковый корпус — пропускать туда
  непроверенные ссылки нельзя (корпус начал бы «подтверждать» выдумки сам себе). Неподтверждённое
  сначала дорабатывается в Редакторе.
- Профильный UI ссылается на `DocFlow.Application` (направление профиль → docflow разрешено,
  ADR-0017) и шлёт команды модуля через общий Mediator.

## Не входит (по потребности)

- Показ построчной разницы «было/стало» (diff) — сейчас редакции сравнивают глазами.
- Кнопки «Открыть в редакторе» из Генератора/реестра методик — перенос текста пока копированием.
- История правок в рамках сессии (принятая редакция замещает текст).
- Прикрепление .docx-файла к регистрируемому документу (текст — в карточке; файл выгружается экспортом).
