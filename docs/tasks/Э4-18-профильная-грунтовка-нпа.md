## Цель
Довести грунтовку до **рабочего состояния**: заменить нейтральные заглушки (`NoCitationExtractor`, `IdentityCitationNormalizer`) настоящими **профильными** реализациями для НПА и добавить **структурный чанкинг** по статьям/пунктам. Без этого GATE-2 (КР-2) проходит на пустышке — ссылки не извлекаются и не проверяются.

## Инвариант ядра (не нарушать)
НПА-специфика (шаблоны ссылок «статья N», «№ N»; чанкинг по статьям) — **доменная, в профиле** (инж-ТЗ §5.3.1.2: «доменная НПА-нормализация от профиля»). Ядро сохраняет нейтральные контракты + заглушки-фолбэк; профиль **переопределяет** через `Replace`, но **не может ослабить** сам инвариант грунтовки (ТБ-041).

## Что сделать
- ✅ `NpaCitationExtractor : ICitationExtractor` — извлечение ссылок НПА из вывода модели (статья/пункт/часть + номер, «№ N», кодексы, Конституция). `[GeneratedRegex]`, только надёжно грунтуемые формы (без ложных «висячих» ссылок).
- ✅ `NpaCitationNormalizer : ICitationNormalizer` — доменная канонизация (ru: склонения «статьи/ст.» → «статья», «№ N» → «№N», кодексы/Конституция); применяется симметрично к ссылке и фрагменту.
- ✅ `NpaStructuralChunker : ITextChunker` — разрез по «Статья N»/«Глава»/«Раздел»; безструктурный текст → абзацный фолбэк; чанк ≤ 1800 симв. (лимит эмбеддера 2048, запас на префикс).
- ✅ Регистрация в профиле (`AddInspectorApplication` → `Replace` трёх сервисов; порядок после `AddCoreGrounding`/`AddCoreIngestion`).
- ✅ Unit-тесты экстрактора/нормализатора/чанкера + сквозной GATE-2 на профильной грунтовке (Confirmed/Unverified/Superseded) + guard-тест композиции (override заглушек). 14 тестов, юнит 79/79, сборка 0 ошибок.

## Осталось (глубже — следующим)
- Привязка ссылки к **норме/редакции** (`LegalNorm`/`NormRevision`), а не только контейнмент по канон-токену — требует протаскивания идентичности нормы в `RetrievedChunk`.
- Калибровка ru/**ky** на золотом наборе (Э4-05, метрика КИ-01, порог Э1).

## Критерии приёмки
- **GATE-2**: вывод со ссылкой, которой нет в извлечённых фрагментах → `Unverified`, не выдаётся как готовый.
- Ссылка «ст. 12» из вывода сопоставляется с фрагментом «Статья 12…» (актуальным) → `Confirmed`; тот же источник неактуален → `Superseded`.
- НПА с «Статья 1…Статья 2…» → чанки по статьям; текст без структуры → абзацный фолбэк.
