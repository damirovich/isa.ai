# Методика расчёта уровня риска подразделения

Источник: инженерный ТЗ «Инспектор AI», Приложение §2 (методики) и §5.2.5.1. Реализация: [`RiskScoreCalculator`](../../src/profiles/inspector/ISC.AI.Profile.Inspector.Domain/Risk/RiskScoreCalculator.cs). Задача: [Э5-01](../tasks/Э5-01-домен-нарушение.md).

## Принцип
Уровень риска подразделения — **детерминированный балл**, вычисляемый КОДОМ (не ИИ) над структурированными данными (нарушения + сроки поручений). Это сделано ради **прозрачности и воспроизводимости приёмки**: одни и те же входные данные всегда дают один и тот же результат. ИИ применяется ТОЛЬКО к текстовым формулировкам (рекомендация/пояснение) и всегда как черновик; сам балл ИИ не считает.

## Формула
```
RiskScore(подразделение, период) =
      w1 · Σ severity_weight(нарушение)   // объём × тяжесть ОТКРЫТЫХ (неустранённых) нарушений
    + w2 · RepeatCount                     // повторяемость: тот же вид в том же подразделении
    + w3 · OverdueRemediationCount         // число просроченных устранений
    + w4 · TrendDelta                      // изменение числа нарушений к предыдущему периоду
```

### Вес тяжести (фиксированный)
| Тяжесть | `severity_weight` |
|---|---|
| низкая | 1 |
| средняя | 2 |
| высокая | 4 |
| критическая | 8 |

### Веса `w1..w4` (конфигурируемые, [`RiskWeights`](../../src/profiles/inspector/ISC.AI.Profile.Inspector.Domain/Risk/RiskWeights.cs))
Стартовые значения (калибруются на этапе Э1):

| Вес | Значение по умолчанию | Смысл |
|---|---|---|
| w1 | 1.0 | объём × тяжесть открытых нарушений |
| w2 | 1.5 | повторяемость |
| w3 | 2.0 | просроченные устранения |
| w4 | 1.0 | рост к предыдущему периоду |

## Балл → уровень (пороги, [`RiskThresholds`](../../src/profiles/inspector/ISC.AI.Profile.Inspector.Domain/Risk/RiskThresholds.cs))
Пороги `T1 < T2 < T3` — конфигурируемы, **калибруются на Э1** (значения ниже — стартовый плейсхолдер):

| Балл | Уровень | Порог по умолчанию |
|---|---|---|
| `балл < T1` | низкий | T1 = 10 |
| `T1 ≤ балл < T2` | средний | T2 = 25 |
| `T2 ≤ балл < T3` | высокий | T3 = 50 |
| `балл ≥ T3` | критический | — |

## Уровень → цвет дашборда (свёртка 4 уровней в 3 цвета)
| Уровень | Цвет |
|---|---|
| низкий | 🟢 зелёный |
| средний | 🟡 жёлтый |
| высокий, критический | 🔴 красный |

## Что настраивается, а что фиксировано
- **Фиксировано (структура):** сама формула, веса тяжести 1/2/4/8, свёртка уровней в 3 цвета — решение исполнителя.
- **Конфигурируемо (калибруется Э1):** веса `w1..w4`, пороги `T1/T2/T3`. Значения по умолчанию — стартовые.
- **Детерминировано (код):** весь балл и уровень. **ИИ:** только текст рекомендации (отдельно, с грунтовкой, с участием человека).

## Проверка (приёмка)
На фиксированном наборе входных нарушений вычисленный уровень **воспроизводим** и совпадает с формулой — модульные тесты [`RiskScoreCalculatorTests`](../../tests/ISC.AI.UnitTests/Profiles/RiskScoreCalculatorTests.cs) (§5.2.5.1).
