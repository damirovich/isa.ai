## Контекст

В архиве Заказчика вместе с фото, видео и аудио лежат документы Word: сводки, справки, задания — и в новом формате
`.docx`, и в старом `.doc` (Word 97–2003), а сканы — в `.pdf`. Импорт ADR-0041 принимает только носители. Документы
можно было ввести лишь по одному через документооборот. Кроме того, текст `.doc` система не читала вовсе: файл
хранился, но в поиск и корпус не попадал.

Решения заказчика 13.10.2026: документы архива — **в документооборот с привязкой к делу**; текст `.doc` — **своим
чтением, без новых библиотек и программ на сервере**.

## Решение

1. **Одна опись на папку архива.** Документы (`.docx`, `.doc`, `.pdf`) идут в той же описи и том же задании, что
   и носители: архив Заказчика разложен по делам, а не по видам файлов. Черновик описи включает и документы.
   Новые необязательные столбцы: **тип документа** (по названию из справочника типов документооборота), **рег.
   номер**, **дата документа**, **название** (краткое содержание).
2. **Документ архива — документ документооборота группы «Хранение»**, прикреплённый к делу из описи (ТФ-ДДЛ-01):
   - гриф и подразделение — **дела** (ТБ-070), как у носителей; подтверждаются той же галочкой (ТБ-024);
   - тип — из описи или общий для задания (выбирается на экране); допустимы только типы группы «Хранение»: у архивного
     документа нет исполнителей и сроков;
   - дата регистрации — «дата документа» из описи, иначе дата из «даты съёмки», иначе дата изменения файла (в итоге
     проверки — счётчик таких строк);
   - краткое содержание — «название» из описи, иначе имя файла; направление — «внутренний»; в примечании — задание
     и строка импорта (происхождение, ТБ-077).
3. **Пакет «Медиа» о документообороте не знает** (ADR-0017). Документ создаёт профиль через новый порт
   `IArchiveDocumentSink`; без профиля с документооборотом строки документов получают отказ «документы этот
   экземпляр не принимает» (поставка по умолчанию).
4. **Проверки при приёме документа** — те же правила, что у носителей: допуск и право оператора перед каждым файлом,
   дело доступно и с подтверждёнными грифом и подразделением, сигнатура содержимого по расширению (`.docx` — ZIP,
   `.doc` — составной файл OLE или RTF, `.pdf` — `%PDF`), предел 100 МБ, контрольная сумма из описи.
5. **Повтор без дублей.** Тот же файл (SHA-256), уже введённый импортом в то же дело, — «дубликат» без второго
   документа. Документ создаётся, и его номер сразу пишется в строку задания: если приём прервался между созданием
   документа и загрузкой файла, повтор строки продолжает тот же документ, а не заводит второй.
6. **Индексация текста — порциями**, как обработка носителей (ADR-0041 п. 7): документы подаются в общую очередь
   задачами документооборота «Индексация документа в корпус» не больше `Media:Import:ProcessingSlots` за раз.
7. **Чтение текста `.doc`** — своим кодом в ядре (`DocTextExtractor`), без сторонних библиотек:
   - составной файл OLE (Compound File Binary, [MS-CFB]) → поток `WordDocument` и таблица `0Table`/`1Table`;
   - текст — по таблице кусков (piece table, [MS-DOC]): куски UTF-16 и 8-битные (кодовая страница 1252 со
     спецтаблицей Word); служебные символы приводятся к абзацам, коды полей отбрасываются, остаётся их результат;
   - `.doc`, который на деле RTF (так сохраняли многие учётные программы), читается простым разбором RTF
     (`\ansicpg`, `\'hh`, `\uN`);
   - не читаются: `.doc` с паролем и форматы Word 6/95 — понятная ошибка, а не пустой текст.
   Извлекатель работает для всех путей ядра: и для импорта, и для документа, загруженного в документооборот вручную.

## Последствия

- **Плюсы.** Архив переносится целиком одной описью; документы сразу видны в деле и ищутся по тексту; `.doc`
  перестал быть «немым» файлом во всей системе; новых зависимостей и установок нет.
- **Минусы и ограничения.** Форматирование `.doc` не извлекается — только текст; Word 6/95 и `.doc` с паролем — отказ.
  Документы архива регистрируются без исполнителей и сроков (группа «Хранение»); исполнение по ним, если нужно,
  ставится вручную.

## Не сделано

- Разбор архивных сводок на поля бланка (ТФ-ДДЛ-04) — архивная сводка вводится документом.
- Перенос баз Access — отдельное решение (ADR-0043).
