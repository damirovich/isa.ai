## Контекст

[АИС ФТ-5.7.2] требует, чтобы система оценивала пригодность кадров для биометрии — резкость, поворот головы,
освещённость — и рекомендовала лучший образец. Конвейер индексации сейчас оценивает лицо только по геометрии
(ТО-мат-07): межзрачковое расстояние, уверенность детектора, лицо не обрезано краем кадра; непригодное лицо не
векторизуется. «Лучшее лицо» трека в карточке носителя выбирается по этому общему баллу, а лучший кадр для эталона
фигуранта не предлагается вовсе. Эталоном кадр делает только человек (ТБ-077).

## Решение

### 1. Оценки кадра — при индексации, у каждого лица

- **Резкость** — дисперсия лапласиана яркости по области лица, приведённой к 96 пикселям по ширине (сравнимо у
  лиц разного размера); оценка 0–1 насыщается: `v / (v + 150)`.
- **Освещённость** — средняя яркость области лица (лучше всего — середина шкалы) и её разброс (контраст):
  `0,6 · (1 − |средняя − 128| / 128) + 0,4 · min(1, разброс / 50)`.
- **Поворот головы** — по пяти точкам лица детектора (глаза, нос, уголки рта), без отдельной модели: наклон
  (roll) — угол линии глаз; поворот (yaw) — смещение носа от середины глаз относительно полурасстояния между глазами;
  кивок (pitch) — положение носа между линией глаз и линией рта. Это **оценка для сравнения кадров между собой**, а не
  измерение угла; оценка позы: `max(0, 1 − max(|yaw| / 60°, |pitch| / 40°))`.
- **Размер** — межзрачковое расстояние: `min(1, расстояние / 80 пикс.)`.
- **Оценка кадра** (0–1) = `0,35 · резкость + 0,30 · поза + 0,15 · освещённость + 0,20 · размер`; у непригодного лица
  (ТО-мат-07) — 0: оно не может быть эталоном.
- Хранится у лица (`media.face`: резкость, освещённость, поворот, кивок, наклон, расстояние между глазами, оценка
  кадра; пусто у лиц, проиндексированных раньше). Веса и нормировки — стартовые, калибруются на пилоте вместе с
  порогами ТО-мат-07. Сбой оценки не роняет индексацию: лицо пишется без оценок.
- Только измерение — изображение не меняется (ТЭ-007). Старые носители получают оценки **переиндексацией** (кнопка
  «Переиндексировать» в карточке носителя, как прежде).

### 2. Ранжирование

Кадры упорядочиваются: сначала пригодные (ТО-мат-07), среди них — по оценке кадра, при её отсутствии (старые лица) —
по прежнему общему баллу, затем по номеру лица. Одно правило — для трека, для фото и для подсказки эталона.

### 3. Карточка носителя

У трека видео и у лица фото — **«лучший кадр»** по оценке кадра (а не по общему баллу) с оценками словами и
процентами: резкость, поворот головы (≈ градусы), освещённость, размер. Лица без оценок помечены «оценок кадра нет —
переиндексируйте». Проценты — оценка пригодности кадра, **не вероятность тождества** (ТЭ-006).

### 4. Карточка фигуранта — «Предложить эталон»

- На вкладке «Эталоны» — блок подсказки: из **подтверждённых и не отозванных появлений** фигуранта на материалах
  **его дела** (эталон берётся только из материалов дела, ТБ-071) — лучший кадр: у видео — среди всех кадров трека
  появления, у фото — само лицо. Уже выбранные эталоны не предлагаются. Показываются вырезка, оценки и сравнение с
  лучшим действующим эталоном; если действующий эталон не хуже — подсказка так и говорит.
- **«Сделать эталоном»** открывает окно «Новый эталон» с уже выбранными снимком и лицом (источник — «Лучший кадр
  носителя № …»); основание, дата пересмотра и замена прежнего — как всегда; эталоном кадр становится только по
  «Добавить» — решение человека (ТБ-077), обычной командой с проверками и журналом.
- Подсказка — запрос под решёткой фигуранта: появления, лица и носители читаются через те же хранилища и порты, что
  карточки; в журнал — `View` с номером фигуранта, без значений (ТБ-030, ТБ-032).

## Последствия

- Миграция `media` `FaceFrameMetrics`: семь необязательных столбцов `media.face`.
- Порт изображений — новый метод измерения лица; порт оценок — чистые функции домена «Медиа».
- Проверки: поза по синтетическим точкам (анфас, поворот, кивок, наклон), оценка и ранжирование, Skia — резкость
  чёткого выше размытого, освещённость тёмного ниже среднего; индексация пишет оценки; подсказка — только материалы
  своего дела, без отозванных и уже эталонов, лучший кадр трека; bUnit — подсказка и окно с выбранным кадром.
