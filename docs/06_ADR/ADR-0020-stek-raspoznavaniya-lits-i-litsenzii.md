## Контекст

Правило проекта — только MIT/Apache-2.0, **включая веса моделей**. Большинство «готовых» стеков распознавания
лиц (InsightFace buffalo/antelope, ArcFace из ONNX Model Zoo, AdaFace) распространяют веса на условиях
«только некоммерческое исследовательское использование» — для ведомственной системы это запрет. Библиотеки
ImageSharp (split-лицензия), Xabe.FFmpeg (CC BY-NC-SA), Emgu CV (GPLv3) — тоже запрещены. Инференс должен
работать на CPU в изолированном контуре без интернета.

## Решение

| Компонент | Роль | Лицензия кода / весов | Решение |
|---|---|---|---|
| **YuNet** (`face_detection_yunet_2023mar.onnx`, OpenCV Zoo) | Детекция: bbox + 5 точек + score | MIT / MIT | Принять |
| **SFace** (`face_recognition_sface_2021dec.onnx`, OpenCV Zoo) | Вектор лица 128-d, вход 112×112 после выравнивания | Apache-2.0 / Apache-2.0 | Принять |
| **Microsoft.ML.OnnxRuntime** (CPU) | Инференс ONNX в процессе | MIT | Принять; GPU-пакеты (CUDA/DirectML) — отдельным согласованием |
| **SkiaSharp** | Декодирование, масштабирование, аффинное выравнивание, вырезки | MIT / Skia BSD-3 | Принять |
| **FFMpegCore** + бинарник **ffmpeg LGPL-сборки** (BtbN `lgpl`) | Раскадровка видео внешним процессом | MIT / **LGPL-3.0** (сборка с `--enable-version3`) | **Принято и поставлено 18.09.2026**: тегированный релиз `autobuild-2026-09-17-13-19`, файл `ffmpeg-n9.0.1-69-g3e11912860-win64-lgpl-shared-9.0.zip`, пин SHA-256 `3FA84213…E5C6`. Обязательства выполнены: текст лицензии (`LICENSE.txt`) в поставке, исходники — по тегу и коммиту `g3e11912860`; линковки нет (внешний процесс). Сборки gyan.dev (GPLv3) не брать |
| InsightFace/ArcFace/AdaFace веса; ImageSharp; Xabe; Emgu | — | non-commercial / split / NC / GPL | **Запрещены** |

Реализация — «вариант A»: чистый ONNX Runtime + собственная пред/постобработка (декодирование выходов YuNet
по формулам OpenCV `FaceDetectorYN`, NMS; преобразование подобия по 5 точкам к шаблону ArcFace 112×112,
RGB 0..255, L2-нормирование выхода `fc1`). Факты живого прогона: YuNet 2023mar — фиксированный вход
640×640 (letterbox), портреты — score ≈ 0,92; SFace — два фото одного человека cosine 0,88, разные люди
0,14–0,15 (порог OpenCV на LFW 0,363 — только точка отсчёта, рабочие пороги — по пилоту, ТО-мат-08).

Поставка: `deploy/offline/export-vision-models.ps1` скачивает модели с **пинами SHA-256** и пишет манифест;
конфигурация `Vision:*:Sha256` обязательна — без пина или при несовпадении модель не загружается
(`ModelFileIntegrity`, fail-closed, ТИ-004). Реальные фотографии людей в репозиторий и тесты не кладутся
(ТО-прог-13): юнит-тесты — на синтетике, живые проверки — вне репозитория.

**Форматы носителей (ТФ-МЕД-01) — ограничение первого среза.** Конвейер декодирует изображения через
SkiaSharp (JPEG, PNG, BMP, WebP, GIF); TIFF и HEIC им не читаются, поэтому в allowlist приёма они не входят —
загрузка отклоняется с понятным текстом, а не уходит в «ошибка обработки». Видео принимается в контейнерах
MP4, WebM, MKV, AVI, MOV (раскадровка — ffmpeg); браузер воспроизводит только MP4/WebM, для остальных
карточка носителя предлагает скачать оригинал. Тип файла сверяется с сигнатурой содержимого при приёме
(подмена типа отклоняется). Поддержка TIFF/HEIC (MIT/Apache-декодер или конвертация ffmpeg при приёме) и
проксируемая MP4-копия для MKV/AVI/MOV — отдельные задачи; до их решения ТФ-МЕД-01 по этим форматам
выполнен не полностью — фиксируется в отчёте этапа.

В системе **нет и не будет** моделей, выводящих по лицу пол, возраст, этничность, эмоции или состояние
здоровья (ТБ-075): в DI регистрируются ровно детектор, векторизатор, оценка качества и раскадровка.

## Последствия

- (+) Полная лицензионная чистота, включая веса; минимальный footprint (две модели ≈ 39 МБ), CPU-инференс.
- (−) Собственная постобработка требует поддержки при смене версии модели (формулы декодирования, шаблон выравнивания) — покрыто юнит-тестами `YuNetDecoderTests`, `SimilarityTransformTests`.
- (+) Раскадровка закрыта 18.09.2026: ffmpeg LGPL-сборки поставляется скриптом `deploy/offline/export-ffmpeg.ps1` (пин SHA-256 архива плюс проверка флагов конфигурации самого бинарника — в сборке не должно быть `--enable-gpl` и `--enable-nonfree`), поставляются только `ffmpeg.exe`, `ffprobe.exe`, библиотеки и `LICENSE.txt` (≈148 МБ; `ffplay` исключён). Конвейер проверен на настоящем видео: `FfmpegFrameExtractorTests` (категория `Video`) — индексы и таймкоды кадров, целостность JPEG, предел числа кадров, контейнеры MPEG-4 и VP9/WebM, отмена, отсутствующий файл.
- (−) Размер поставки: библиотеки LGPL-сборки со всеми разрешёнными кодеками весят ≈148 МБ (основное — `avcodec` 86 МБ). В git не хранятся (`deploy/offline/ffmpeg/` в `.gitignore`), переносятся папкой `deploy/offline` целиком по манифесту `ffmpeg.sha256`.
- (!) Обязательство при смене версии: одновременно менять тег, имя файла и пин в скрипте, заново прогонять `dotnet test --filter "Category=Video"` и переносить поставку в контур. Прогон без поставки — `--filter "Category!=Video"`; тест намеренно падает с инструкцией, а не пропускается молча.
