## Контекст

Искать приходилось по разделам: дела — в реестре, фигурантов — в карточке дела, слова записи — в медиатеке одного
дела, сводки — в карточке дела, документы — в документообороте. ТФ-ПСК-01 требует одного поискового окна: точный
поиск по полям (ФИО, псевдоним, госномер, адрес, № задания, дата) и поиск по тексту (сводки и справки, расшифровки),
всё — в пределах области дел субъекта (ТБ-071), с журналом искомого текста (ТБ-032).

## Решение

1. **Одна строка поиска — один запрос `UnifiedSearchQuery` — одна запись журнала.** Запись `Search`
   `investigation:search:kinds=…;direction=…;text=…`: искомый текст — в чувствительной части записи (ТБ-032), гриф
   записи — не ниже допуска субъекта (поведение аудита). Отдельные поиски пакетов (по расшифровкам одного дела) не
   вызываются — у единого поиска своя запись, без дублей.
2. **Область — доступные субъекту дела** по полной решётке и роли (тот же список, что реестр дел, ТБ-020/071), при
   выборе отдела — только дела отдела (ADR-0039). Всё остальное ищется ТОЛЬКО внутри этих дел, и каждое хранилище
   повторно применяет свою решётку на стороне БД (строка фигуранта, адреса, транспорта, сводки, фрагмента расшифровки,
   документа — у каждой свои гриф и подразделение). Недоступное в выдаче не появляется ничем, даже числом.
3. **Что и как ищется (ТО-мат-11).** Текст запроса нормализуется один раз (`SearchTerms`): для текста — нижний
   регистр, «ё» → «е», пробелы сжаты, ө/ү/ң сохраняются; для госномера — только буквы и цифры, латиница вместо
   кириллических омоглифов; для адреса — правило нормализации адреса («улица» = «ул.»); дата «дд.мм.гггг» и год — для
   даты рождения. Совпадение — подстрока (не морфология: словаря киргизского нет).
   - **Дела** — номер, № задания, название.
   - **Фигуранты** — ФИО, псевдоним, гражданство (ADR-0055); дата рождения (точная дата) или год рождения.
   - **Автотранспорт** — госномер (подстрока нормализованного: «123ABC» находит «01 KG 123 ABC»), марка, модель.
   - **Адреса** — адреса фигурантов и место жительства из анкеты (подстрока нормализованного адреса).
   - **Телефоны** (ADR-0055) — запрос из цифр и «+ - ( ) .», от 5 цифр и не дата, нормализуется как номер (только
     цифры, 996 для местных) и ищется подстрокой нормализованного номера: «0555 123 456» и «123456» находят
     «+996 555 123 456».
   - **События** (ADR-0056) — название и описание события, роль участника, марка, адрес и госномер контакта (адрес и
     госномер — по нормализованным значениям) — только по участникам с отметкой «в общем поиске» и уровнем не «неверно»,
     доступным субъекту в делах области.
   - **Сводки и справки** — текст полей бланка (как поиск внутри дела, ADR-0031).
   - **Расшифровки** — слова записей носителей этих дел (как поиск по расшифровкам дела, ADR-0026).
   - **Документы дел** — регистрационный номер и краткое содержание документов, привязанных к этим делам (видимость
     документа — решётка документооборота).
4. **Выдача — разделами со счётчиками, по 50 в разделе.** Больше — пометка «показаны первые 50, уточните запрос».
   Можно ограничить поиск видами (только фигуранты, только расшифровки…). Каждая строка ведёт на место: дело — в
   карточку дела, фигурант, его адрес и машина — в карточку фигуранта, сводка — в карточку сводки, фрагмент
   расшифровки — в карточку носителя на этом месте записи (`?t=`), документ — в карточку документа (ТФ-ПСК-02).
   Совпадение в строке выделяется (разбиением строки, без вставки разметки — защита от XSS, как у расшифровок).
5. **Страница «Поиск»** (`/search`) в разделе «Дела» меню; виден тем, кому открыт реестр дел (право матрицы
   «Дашборд и реестр дел»). Запрос, виды и отдел — в адресе страницы: «Назад» из карточки возвращает к той же выдаче.

## Последствия

- **Плюсы.** Одно поле вместо пяти разделов; госномер и адрес находятся при любом написании; из выдачи — сразу на
  место; один ответ на вопрос «кто что искал» в журнале.
- **Минусы.** Возврат «Назад» повторяет поиск (и запись журнала) — это новое обращение к материалам. Документы
  проверяются пачками по 200 идентификаторов — при тысячах документов в делах поиск по документам медленнее прочих.
- **Не сделано.** Поиск по OCR-тексту документов и по смыслу (ТФ-ДДЛ-03/06) — через корпус ядра, отдельной задачей;
  поиск по лицу остаётся своим сценарием с делом и основанием (ТФ-ПЛ-01, ТБ-071); фильтр по периоду и статусу;
  нечёткое сравнение ФИО — только по решению заказчика (ТО-мат-11).
